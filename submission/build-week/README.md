# RAVENCRY — OpenAI Build Week submission packet

This folder contains the evidence for the **Evidence Briefing Desk** extension.
It is deliberately separate from the Qwen Hackathon submission materials.

| File | Use |
| --- | --- |
| `live-briefing-directors-script.md` | Record the live GPT briefing insert for the Build Week video. |
| `manual-live-briefing-check.md` | Repeatable local product check and expected safe outcomes. |
| `readme-build-week-section.md` | Fact-checked Build Week section to adapt into the repository README. |
| `submission-evidence.md` | Commit trail, verification results, `/feedback`, video, and Devpost checklist. |

## Important truthfulness rules

- Runtime briefing uses **`gpt-4o-mini`**. Do not call it a GPT-5.6 runtime
  feature.
- Codex and GPT-5.6 were used throughout the Build Week implementation work;
  describe that collaboration in the README and video using the evidence here.
- The Desk never sends, approves, or suppresses an alert. It exposes evidence
  and retains a visible human approval gate.
- Rewrite the Devpost narrative in the team's own voice. This packet records
  verified facts; it is not a final Devpost description to submit verbatim.
